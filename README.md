# Gaurav Prabhu K - Senior Backend Engineer Portfolio

Personal portfolio highlighting Python backend engineering, AWS event-driven services, distributed systems, and applied AI/RAG work. The site is a static GitHub Pages project built with HTML, CSS, and vanilla JavaScript.

**Live site:** [codeb7.github.io/gp-portfolio](https://codeb7.github.io/gp-portfolio/)

## Project structure

```text
gp-portfolio/
├── index.html                    # Portfolio, experience, projects and contact
├── resume.html                   # Semantic, print-ready CV source
├── output/pdf/                   # Downloadable CV PDF
├── css/style.css                 # Responsive visual design and print styles
├── js/main.js                    # Navigation, filters, copy-to-clipboard
├── images/                       # Profile and community photos
└── _config.yml                   # GitHub Pages/Jekyll metadata
```

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server. No build step is required.

The page uses Bootstrap 4.6.2 and jQuery from CDNs for its responsive grid and navigation, plus Google Fonts. The site content and project filters are plain HTML/CSS/JavaScript.

## CV

The portfolio links to an ATS-friendly PDF at `output/pdf/gaurav-prabhu-k-cv.pdf`. `resume.html` is the editable semantic source and can also be printed to PDF from a browser. Update both files together when experience or contact details change.
